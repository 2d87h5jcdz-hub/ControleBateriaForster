# Controle de Bateria Forster

App de controle de vendas, devedores, estoque e compras de baterias, com preço em dólar turismo convertido na hora da venda.

- `app/index.html`: o app inteiro (HTML, CSS e JS num arquivo só). É o mesmo arquivo do protótipo.
- `assets/`: logo, ícone e tela inicial (`icon-only.png` 1024×1024, `splash.png` e `splash-dark.png` 2732×2732).
- Cada push na `main` gera o `Forster.ipa` na aba **Actions** (artefato `Forster-ipa`).

Os dados ficam num arquivo dentro do app (`Library/dados.json`). Use **Ajustes › Salvar backup** para levar os dados para outro celular.
